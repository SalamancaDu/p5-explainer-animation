# 一笔一笔作画

默认 10 秒水彩，主题由用户给出，如“雨后的荷塘，一只红色蜻蜓停在荷叶尖上”。水粉、油画使用各自笔身规则。程序笔触效果不等于真实颜料物理模拟。

## 笔触

每笔都有笔身、刷毛啃过的两侧毛边、内部明暗条纹、收尾干笔飞白。笔身透明度按媒介区分，不能同时要求水彩完全不透明与透明叠色。

- 水彩：单笔透明度约 60–90/255；一侧加深色沉积边，笔迹内约一个深色颗粒点，按面积少量调整。主要色层叠两层，重叠加深；不每帧盖同一笔导致越播越黑。
- 水粉／油画：基本不透明，一侧带第二种颜色；假设左上来光，一侧亮边、一侧暗边，随笔触方向变化，不统一描边。
- 不用平滑渐变、裸露的纯色大多边形、柔光圈替代绘画。几何可作蒙版，但可见颜色由有内部变化的笔触构成。透明笔触的自然叠色过渡不属于禁止的电脑渐变。
- 先用宽约 50–100 px 大笔铺天与地／水，笔从画外开始覆盖边缘；中笔塑形；小而准的高光只在视觉中心。
- 相邻笔触色相与明度差几个百分点，不完全相同。远处相对冷、淡，细节笔小；近处更深、局部笔大，后画。背景铺色大笔不受远处细节小笔限制。

## 过程与图层

初始化排好笔触，保存稳定 ID、开始帧、形状、颜色、图层。draw 只将新到时的笔触画入对应累积层，不每帧重画全部历史。

默认每帧落 2–10 笔，通过区域连续成形与主笔强调，让过程可读。太密而像擦显整图时降低同时出现量或延长主笔显露，不机械凑笔数。

| 时间 | 步骤 |
| --- | --- |
| 0–2 秒 | 大色与远景 |
| 2–4 秒 | 主体大形 |
| 4–6 秒 | 局部与前景 |
| 6–8 秒 | 细节、中心、高光 |
| 8–10 秒 | 不再添笔，水面、叶片、光线微动 |

首个有效帧以帧 0 或之前预排的背景笔触覆盖边缘，仍由笔触组成，不长时间暴露整屏白底；后续正常每帧 2–10 笔。“不露白纸”针对意外漏铺的边缘，不禁止笔迹内部干笔飞白。

水面、叶片、蜻蜓、局部光等需动的对象保留独立层，完成后轻移、轻旋或局部变形，不把整张画摇晃当成局部活尾。

循环噪声可沿噪声空间的圆采样：`noise(cx+r*cos(theta), cy+r*sin(theta), layer)`，theta 来自局部帧。还需匹配起止姿态和速度；调用 noise 本身不证明可循环。

最后正片叠底纸纹。默认自动播放一轮后保留末帧；要求循环时先清空所有累积层。三方案指定各 6 秒时，以约 80% 作画、20% 活尾重排，不继续要求前 8 秒作画。

## 累积状态

用模板 `kit.accumulator(events, apply, clear)`：前跳补画缺失笔触；同帧不重复画；后退清空后重建；reset 重置所有层与游标。检查顺序播放与中段直接定位一致、回退无未来笔迹、重播不加深、尾段确有局部微动、笔触有刷毛宽度而不是细线排线。
