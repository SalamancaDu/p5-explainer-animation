# 手绘涂鸦

默认 5 秒，米白纸、黑色马克笔、一个强调色。原例是珊瑚红与红头发、大眼睛、圆脑袋的 Q 版小女孩；它们是可替换的单次输入，不是固定品牌或角色。

原例动作：说话 → 气泡里的话变成箭头 → 尽头画出小画或星星 → 角色开心跳一下。根据口播调整因果，不把所有句子套进同一故事。

## 线条

- 长线约 12–20 帧写完，短词或短笔组约 3–5 帧。按路径弧长逐段显露，先慢、中间快、最后慢；不匀速扫遮罩冒充书写。
- 压力带：两端收尖，中间粗细变化；沿路径法线构造两侧边界，不只画等宽描边。
- `boil on threes`：每 3 帧重画，局部抖动 1–2 px，整笔漂移 2–4 px。稳定笔迹 ID 与独立相位决定更新桶，如 `floor((frame + phase) / 3)`；同桶不变，整页不同时跳。
- 圆从偏上的位置起笔。留开口时约画 0.9 圈；若采用原例的 1.1 圈，末段偏离原轨迹形成错位重叠收笔。两者选一，不同时要求严格开口与同轨绕满一圈以上。
- 箭头先杆，后分两笔画头；方框角允许交叉出头。
- 填色与所属线条共用更新桶和整体漂移，局部略错位，像印歪；不独立乱跳。
- 用纸纹蒙版从笔迹中咬掉少量墨点，只影响线条，不侵蚀填色；底纸纹理另作一层。
- 文字整词作为一个单元每 3 帧轻微位移、旋转，不逐笔抖。默认关键词不超过 3 个汉字；中文用 Noto Sans SC 或 Noto Serif SC 粗体，加载完再计时。

普通字体不提供真实笔顺。需要逐笔写汉字时必须构建正确路径，否则采用整词出现或既定路径显露，不宣称模拟了真实笔顺。

## 结尾与检查

最后 1 秒不新增元素，已经画好的线条和填色继续轻微重绘，角色落定，重点稳定。默认硬切重播；首尾姿态与噪声周期匹配后才能称无缝循环。

首帧有角色或正在显露的笔迹。检查全图与缩放后的线宽、文字、表情。压力带与侵蚀缓存有限版本，避免逐帧全像素计算。
