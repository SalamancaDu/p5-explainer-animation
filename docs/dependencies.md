# 运行依赖与离线使用

## 默认运行

HTML 内联播放器与场景，但联网加载 p5.js **1.11.11** 和 Noto Sans SC 900 字重。依赖地址位于每个页面的 CONFIG。库版本固定；Google Fonts CSS 与字体子集是外部资源，跨环境不保证完全相同的字体文件或像素结果。

字体样本 `fontSample` 应包含画面全部字符。准备完成后才开始时间线；无法加载时显示原因。页面不上传口播内容或作品文件到本项目服务器，外部资源请求仍会连接相应 CDN / 字体服务。

## 离线准备

当前发行包不包含离线依赖包，也未把“完全离线”作为已验证能力。需要离线时：

1. 准备对应 p5.js 文件及满足所需字符、字重的字体文件。
2. 核对来源与许可，保留对应版权和许可证；参考[第三方说明](../THIRD_PARTY_NOTICES.md)。
3. 将库、字体 CSS 和 `@font-face` 指向本地文件，或在许可条件满足时内嵌。外置文件意味着需要连同目录分享。
4. 禁止网络后实际检查加载、中文、播放和导出，再称离线交付完成。

不建议静默退回系统字体，这会改变中文形态、文本宽度与布局。

## 开发依赖

构建：Python 3.10+，仅标准库。静态检查还需要已有 Node.js，以检查 JavaScript 语法。

浏览器回归：已有 Node.js、Playwright 包和 Chrome / Chromium。脚本接受模块入口和浏览器路径，不安装包、不下载浏览器。

预览整理：已有 Python Pillow 和 FFmpeg。仅用于缩小实际截图、合成 README 和转换展示动图，不是使用 Skill 或播放示例的必需条件。
