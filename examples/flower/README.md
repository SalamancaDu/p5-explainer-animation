# 同一句话，三个方向

**主题：把零散的想法，变成一朵花。** 这是视觉隐喻，无外部统计、声音或摄影素材。

| 文件 | 表达与节奏 | 源码 |
|---|---|---|
| [a.html](a.html) | 拼贴纸片依次拍入组装花朵，最后一秒全部冻结 | [collage.js](source/collage.js) |
| [b.html](b.html) | 人物、想法气泡、箭头、逐笔开花；结尾保持线条微动 | [doodle.js](source/doodle.js) |
| [c.html](c.html) | 宽笔铺色，花枝和花瓣分层形成；最后约 20% 花枝微动 | [painting.js](source/painting.js) |

[compare.html](compare.html) 同步比较三种实际画面。默认 1920×1080、30 fps、180 个逻辑帧，固定种子。水彩为六秒探索版；Skill 默认单独作画模式为十秒，二者按不同任务调整节拍。

```text
用 $p5-explainer-animation 为“把零散的想法，变成一朵花”
做复古拼贴、手绘涂鸦、水彩作画三个方向，各 6 秒。
同一主题采用不同动作结构，交付可同步比较的 HTML。
```

单独页面：空格播放暂停、Home 重播、S 导出当前 PNG、R 录制一轮静音 WebM。联网依赖与限制见[使用指南](../../docs/getting-started.md)。

源码保留材质与动作细节，未采用真实颜料模拟。此组作品是维护者的实现案例，不能据此保证任意代理都能一次生成相同质量。
